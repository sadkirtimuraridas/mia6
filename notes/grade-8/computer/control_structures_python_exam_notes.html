1. Control Structure

A control structure is a programming construct that affects the flow of execution of a program.

Sequential statements

Statements execute one after another in the order in which they appear.

Selection statements

Statements allow a program to make decisions based on conditions.

Iterative statements

Statements repeat a task based on a given condition. They are also called looping statements.

2. Sequential Statements

Sequential statements are executed one after another without any jump.

print("Hello")
print("Welcome")
print("Python")

Output:

Hello
Welcome
Python

3. Selection Statements

Selection statements are used when a program must choose which statements to execute based on a condition.

A. The if statement

The if statement executes a block of code only when the given condition is true.

if condition:
    statement(s)

Example:

num = int(input("Enter a number: "))

if num > 0:
    print("Positive number")

If the user enters 15, the output is Positive number. If the condition is false, the statements inside the if block are not executed.

B. The if-else statement

If the condition is true, the if block executes; otherwise, the else block executes.

if condition:
    statement(s)
else:
    statement(s)

Example: Finding the greater of two numbers

a = int(input("Enter the first number: "))
b = int(input("Enter the second number: "))

if a > b:
    print("First number is greater")
else:
    print("Second number is greater")

C. The if-elif-else statement

It evaluates multiple conditions and executes the block corresponding to the first true condition. If none is true, the else block executes.

if condition1:
    statement(s)
elif condition2:
    statement(s)
elif condition3:
    statement(s)
else:
    statement(s)

Example: Grading a student according to marks

marks = int(input("Enter marks: "))

if marks >= 90:
    print("Grade A+")
elif marks >= 80:
    print("Grade A")
elif marks >= 70:
    print("Grade B")
elif marks >= 60:
    print("Grade C")
elif marks >= 50:
    print("Grade D")
else:
    print("You need to work hard!")

For an input of 84, the output is Grade A.

D. Nested if statement

A nested if statement means an if statement is placed inside another if statement.

if condition1:
    if condition2:
        statement(s)

Example:

num = 10

if num > 0:
    if num < 20:
        print("Number is between 0 and 20")

4. Iterative Statements (Loops)

Iterative statements repeat a block of statements based on a given condition. Python provides the for loop and the while loop.

A. The for loop

A for loop repeats a set of statements a specified number of times or iterates over a sequence such as a list, string, or tuple.

for variable in range(start, stop, step):
    statement(s)
ParameterMeaning
startStarting number; default is 0.
stopEnding limit; this value is excluded.
stepIncrement or decrement between numbers; default is 1.

The range() function generates a sequence of numbers.

Example 1: Using only the stop value

for i in range(5):
    print(i)
0
1
2
3
4

Example 2: Using start and stop values

for i in range(3, 7):
    print(i)
3
4
5
6

Example 3: Using start, stop and step values

for i in range(1, 10, 2):
    print(i)
1
3
5
7
9

Example 4: Printing numbers in reverse order

for i in range(10, 0, -1):
    print(i)

This prints numbers from 10 down to 1.

B. The while loop

A while loop repeats a block of statements as long as the given condition is true.

while condition:
    statement(s)
    increment_or_decrement

Example:

count = 1

while count < 5:
    print(count)
    count += 1

Output:

1
2
3
4
Important: Update the loop variable when necessary. Otherwise, the loop may run indefinitely.

5. Jump Statements

Jump statements change the normal flow of execution in a loop. This chapter covers break and continue.

A. The break statement

The break statement immediately terminates the loop, and program execution continues with the statement after the loop.

for number in range(10):
    if number == 5:
        break
    print(number)

print("Out of loop")

Output:

0
1
2
3
4
Out of loop

B. The continue statement

The continue statement skips the remaining statements in the current iteration and moves to the next iteration of the loop.

for number in range(6):
    if number == 3:
        continue
    print(number)

Output:

0
1
2
4
5

The number 3 is skipped, but the loop continues.

Difference between break and continue

breakcontinue
Terminates the loop completely.Skips only the current iteration.
Control moves outside the loop.Control moves to the next iteration.
Stops further iterations.Further iterations continue.

8. Quick Revision: Questions and Answers

  1. What is a control structure?
    A control structure is a programming construct that affects the flow of execution of a program.
  2. Name the three types of control structures.
    Sequential statements, selection statements, and iterative statements.
  3. What is a selection statement?
    A statement used to select which block of code executes based on a condition.
  4. What is a nested if statement?
    An if statement placed inside another if statement.
  5. What is an iterative statement?
    A statement that repeats a block of code based on a condition.
  6. Name the two types of loops in Python.
    for loop and while loop.
  7. What is the purpose of the range() function?
    It generates a sequence of numbers for use in loops.
  8. Is the stop value included in range()?
    No. The stop value is excluded.
  9. What does the break statement do?
    It terminates the loop immediately.
  10. What does the continue statement do?
    It skips the remaining statements in the current iteration and moves to the next iteration.
  11. Which statement is used to evaluate multiple conditions?
    The if-elif-else statement.
  12. Which statement is generally used when the number of iterations is known in advance?
    The for loop.
