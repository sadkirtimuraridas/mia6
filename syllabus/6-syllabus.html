Grade 6 Syllabus

Subject: Computer

Book Name: Trackpad 6

Exam Chapter Number and Name Project / Activity
Pre-Mid / CT1
  • Chapter 1: Fundamentals of Computer
  • Chapter 2: Formulas and Functions in Excel 2021
  • Chapter 3: Charts in Excel 2021
 Computer Lab Project

Enter a set of data in an Excel worksheet. Calculate the total sales of various components by using sales addresses and apply bold effects to the total sales.
Mid-Term / CT2
  • Chapter 2: Formulas and Functions in Excel 2021
  • Chapter 4: Krita – An Introduction
  • Chapter 5: Learn HTML5 and CSS3
  • Chapter 6: Formatting a Web Page
  • Chapter 7: Introduction to Mobile Apps
 HTML Project

Create a web page with these details:

  • Web page title: animals
  • Main heading: types of animals, in white
  • Background colour: cyan
  • Text colour: black
Post-Mid / CT3
  • Chapter 8: Internet Services
  • Chapter 9: Algorithm, Flowchart and Mind Maps
 Chart Paper Activity

Take a chart paper and draw all the symbols used while creating a flowchart. Also mention the names and the use of each symbol.
Annual / CT4
  • Chapter 5: Learn HTML5 and CSS3
  • Chapter 8: Internet Services
  • Chapter 9: Algorithm, Flowchart and Mind Maps
  • Chapter 10: Introduction to Python
  • Chapter 11: Intelligence and AI Approaches
 Computer Lab Project – Python

Visit the computer lab and perform the following actions:

  1. Write a Python program that asks the user for their name and prints a greeting message using their name.
  2. Prompt the user to input two numbers, then calculate and display their sum.

Subject: Artificial Intelligence

Book Name: Touchpad 6

Exam Chapter Number and Name Project / Activity
Pre-Mid
  • Chapter 1: Introduction to AI and Automation
 Chart Paper Project

Take a chart paper and write the difference between human intelligence and artificial intelligence, using images or drawings to highlight the differences visually.
Mid-Term
  • Chapter 1: Introduction to AI and Automation
  • Chapter 2: AI Around Us
 Chart Paper Project

Discuss 4–5 AI applications used in daily life. You can use images or drawings purposefully.
Post-Mid Term
  • Chapter 3: Exploring AI Domains
 AI Domains Project

Draw diagrams of each domain and add examples from daily life. Make a neat cover page titled “AI Domains Project”.
Annual
  • Chapter 3: Exploring AI Domains
  • Chapter 4: Computer Vision and Its Applications
 Research Project

Research and summarise the use of AI in face-recognition technology, for example, unlocking a smartphone or using a security system. Discuss how it works and any ethical concerns, such as privacy.
